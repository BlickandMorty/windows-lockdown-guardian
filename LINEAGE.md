# Lineage

Reconstructed from the complete Windows lockdown task history and the later permanent-guardian work. Feature lineage includes the original shared lockdown library, Core/Full profiles, hosts and browser-policy layers, SYSTEM network enforcer, NextDNS denylist export, uninstall resilience, protected AGENTS/rule copies, cross-repair guardians, HMAC manifests, and verification reports.

The public implementation is intentionally clean-room and portable. It excludes live machine identifiers, secrets, personal policies, temporary exception scripts, and any removal or bypass workflow for permanent hard gates.
